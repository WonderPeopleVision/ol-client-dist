# ol-client-dist

ProjectOL 클라이언트 배포 (GitHub Releases).

## 런처 다운로드
아래 파일을 받아 실행하세요:

- [OLExternalLauncher.exe](https://github.com/WonderPeopleVision/ol-client-dist/raw/main/OLExternalLauncher.exe)  (실행파일 단독)
- [OLExternalLauncher_dist.zip](https://github.com/WonderPeopleVision/ol-client-dist/raw/main/OLExternalLauncher_dist.zip)  (실행파일 + 설명서)

## 사용법
1. OLExternalLauncher.exe 실행
2. 버전 선택 -> 폴더 선택 -> 다운로드 -> 실행
3. 7-Zip 이 없으면 실행 중 자동 설치(winget)됩니다.
